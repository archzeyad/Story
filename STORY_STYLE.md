# Tawfik & Shokry Story Style

This file records the approved permanent presentation rules for every future story in this library.

## Default page layout

- Keep the artwork completely clean. Do not bake speech bubbles, captions, dialogue, or page numbers into the image.
- Place a compact cream story panel directly below the illustration.
- The panel is about 20% smaller than the approved dialogue-layout prototype: desktop minimum around 122 px and mobile minimum around 138 px. Let it grow only when required for legibility.
- Use one short narrator sentence only when useful, then write the scene as character dialogue.
- Prefix each spoken line with a small colored speaker-name chip.
- Keep the page-number badge small and inside the text panel, never over the artwork.
- Reuse the shared `dialogue-book.css` and `dialogue-book.js` files.

## Image and performance rules

- Publish clean 960 x 640 WebP pages at about quality 70.
- Lazy-load the current page and preload only the next page.
- Keep expressions faithful to the scene: happiness, fear, sadness, tiredness, concern, and regret must be visible and accurate.
- Proofread all Arabic text before publishing.
